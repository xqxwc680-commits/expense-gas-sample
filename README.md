# 経費・領収書管理シート（GAS 自動集計サンプル）

## 何ができるか
- スプレッドシートの「入力」シートに領収書データ（日付・支払先・科目・金額・メモ）を記録し、入力ミスを自動チェックできます。
- 銀行・カード明細を想定した CSV（日付,支払先,金額）を、重複を防ぎながら「入力」シートへ追記できます。
- メニュー操作または毎月1日の自動実行トリガーで、科目別の件数・合計をまとめた「集計_YYYY-MM」シートを自動生成します。

## 画面のイメージ
- **「入力」シート**: 1行1件で明細を記録するシートです。科目列にはプルダウンが設定され、日付・金額・科目に不備がある行は背景が薄い赤色で強調表示されます。
- **「集計_YYYY-MM」シート**: 指定した月の集計結果が出力されるシートです。各科目（旅費交通費・消耗品費など）の件数と金額合計、および最下段に月全体の合計が表示されます。

## 使い方
1. Google スプレッドシートを新規作成し、「拡張機能」→「Apps Script」を開きます。
2. 本リポジトリの `Code.gs` と `appsscript.json` をエディタに貼り付けて保存し、スプレッドシートを再読み込みします。
3. 上部メニューに増えた「経費ツール」→「入力シートを準備」を実行します。
4. 「経費ツール」→「CSVを取り込む（貼り付け）」から `sample_data.csv` の内容を貼り付け、各行の科目をプルダウンから選びます。
5. 「経費ツール」→「月次集計を作る」で年月（例: `2026-11`）を入力すると、集計シートが作成されます。

## 工夫した点
- **二重取り込み防止**: 「日付・支払先・金額」の組み合わせをキーとして既存行と照合し、同じ明細の重複追記を防いでいます。
- **入力チェック（非破壊）**: 空の日付・一覧外の科目・半角数字以外の金額を色付けして知らせるだけで、元データを勝手に書き換えません。
- **数式インジェクション対策**: CSV の値が `= + - @` で始まる場合は文字列として取り込み、数式として実行されないようにしています。
- **最小権限の設計**: `appsscript.json` のスコープを「現在開いているスプレッドシートのみ（`spreadsheets.currentonly`）」とトリガー管理に限定し、Gmail や Drive 全体へのアクセス権を要求しません。

## 今後の拡張案
- 税率（8%・10%）やインボイス登録番号の有無を記録し、消費税区分ごとの集計を追加する。
- 「設定」シートを追加し、コード編集なしで科目一覧をカスタマイズできるようにする。
- 年間の月別推移をまとめた「年次サマリー」シートを自動生成する。
